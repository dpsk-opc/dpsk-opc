# Task 09: 全局样式与 Electron 适配

**版本**: v1.0.4  
**优先级**: P1  
**预估工时**: 1h  
**依赖**: Task 01, Task 02

---

## 任务目标

完善全局样式，添加设计原则中定义的变量和 Electron 桌面端适配。

## 涉及文件

### 修改文件
- `cat/src/global.less` - 全局样式变量
- `cat/src/app.ts` - 添加 Electron 相关配置

## 实现要点

### 1. 全局样式变量

```less
// global.less

// ============= 设计原则中的样式变量 =============

// 配色系统
@primary-color: #1890ff;
@success-color: #52c41a;
@warning-color: #faad14;
@danger-color: #ff4d4f;
@background-color: #ffffff;
@text-color: #262626;
@text-color-secondary: #8c8c8c;
@border-color: #d9d9d9;
@overlay-color: rgba(0, 0, 0, 0.45);

// 间距系统 (8px 网格)
@spacing-xs: 4px;
@spacing-sm: 8px;
@spacing-md: 16px;
@spacing-lg: 24px;
@spacing-xl: 32px;
@spacing-xxl: 48px;

// 圆角规范
@radius-sm: 6px;
@radius-md: 8px;
@radius-lg: 12px;
@radius-round: 50%;

// 字体规范
@font-size-xs: 12px;
@font-size-sm: 13px;
@font-size-base: 14px;
@font-size-lg: 16px;
@font-size-xl: 18px;
@font-size-xxl: 20px;

// 动画时长
@transition-fast: 150ms;
@transition-normal: 300ms;
@transition-slow: 500ms;

// 侧边栏
@sidebar-width: 260px;

// 汉堡菜单
@hamburger-size: 40px;
@hamburger-offset: 8px;
@hamburger-top: 16px;

// ============= 全局重置 =============

* {
  box-sizing: border-box;
}

html,
body {
  margin: 0;
  padding: 0;
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial,
    'Noto Sans', sans-serif, 'Apple Color Emoji', 'Segoe UI Emoji', 'Segoe UI Symbol',
    'Noto Color Emoji';
  font-size: @font-size-base;
  line-height: 1.6;
  color: @text-color;
  background-color: @background-color;
}

#root {
  min-height: 100vh;
  min-width: 800px; // Electron 最小宽度
}

// 滚动条样式
::-webkit-scrollbar {
  width: 6px;
  height: 6px;
}

::-webkit-scrollbar-track {
  background: transparent;
}

::-webkit-scrollbar-thumb {
  background: rgba(0, 0, 0, 0.15);
  border-radius: 3px;
}

::-webkit-scrollbar-thumb:hover {
  background: rgba(0, 0, 0, 0.25);
}

// 选中文本样式
::selection {
  background: rgba(24, 144, 255, 0.3);
}

// 焦点样式
:focus-visible {
  outline: 2px solid @primary-color;
  outline-offset: 2px;
}

// 链接样式
a {
  color: @primary-color;
  text-decoration: none;

  &:hover {
    color: #40a9ff;
  }
}

// ============= Electron 适配 =============

// Electron 禁用文本选择（可选）
.electron-no-select {
  -webkit-user-select: none;
  user-select: none;
}

// Electron 禁用右键菜单（可选）
.electron-no-context {
  -webkit-app-region: no-drag;
}

// 可拖动区域
.electron-drag {
  -webkit-app-region: drag;
}
```
