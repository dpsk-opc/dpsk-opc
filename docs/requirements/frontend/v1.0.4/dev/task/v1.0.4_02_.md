# Task 02: 路由重构与页面迁移

**版本**: v1.0.4  
**优先级**: P0  
**预估工时**: 2h  
**依赖**: Task 01 (BasicLayout)

---

## 任务目标

调整 UmiJS 路由配置，将 Chat 页面迁移到新的布局中，并删除独立的 Home 页面。

## 涉及文件

### 修改文件
- `cat/src/app.ts` - 添加路由配置和 BasicLayout
- `cat/src/pages/Chat/index.tsx` - 移除"返回首页"按钮
- `cat/src/pages/Chat/index.less` - 调整样式以适配新布局

### 删除文件
- `cat/src/pages/Home/index.tsx`
- `cat/src/pages/Home/index.less`

### 新增文件
- `cat/src/pages/Chat/agents/index.tsx` - Agent 列表页 (L2)
- `cat/src/pages/Chat/agents/$id.tsx` - Agent 详情页 (L3)
- `cat/src/pages/Chat/agents/new.tsx` - 新建 Agent (L3)
- `cat/src/pages/Chat/history/index.tsx` - 会话历史 (L2)
- `cat/src/pages/Chat/settings/index.tsx` - 设置页面 (L2)

## 路由结构

```
/                     → 重定向到 /chat
/chat                 → BasicLayout + Chat (默认子路由)
/chat/agents          → BasicLayout + AgentList
/chat/agents/new      → BasicLayout + AgentForm
/chat/agents/:id      → BasicLayout + AgentDetail
/chat/history         → BasicLayout + History
/chat/settings        → BasicLayout + Settings
```

## 实现要点

### 1. 路由配置 (app.ts)

```typescript
// app.ts
export const request: RequestConfig = {
  // ... existing config
};

export const routes: Routes[] = [
  {
    path: '/',
    component: '@/pages/Home/index', // 临时重定向
  },
  {
    path: '/chat',
    component: '@/layouts/BasicLayout',
    routes: [
      {
        path: '/chat',
        component: '@/pages/Chat/index',
      },
      {
        path: '/chat/agents',
        component: '@/pages/Chat/agents/index',
      },
      {
        path: '/chat/agents/new',
        component: '@/pages/Chat/agents/new',
      },
      {
        path: '/chat/agents/:id',
        component: '@/pages/Chat/agents/$id',
      },
      {
        path: '/chat/history',
        component: '@/pages/Chat/history/index',
      },
      {
        path: '/chat/settings',
        component: '@/pages/Chat/settings/index',
      },
    ],
  },
];
```

### 2. Home 页面重定向

将 `cat/src/pages/Home/index.tsx` 改为简单的重定向组件：

```tsx
import { Navigate } from '@umijs/max';

export default () => <Navigate to="/chat" />;
```

### 3. Chat 页面调整

- 移除"返回首页"按钮 (因为现在首页就是聊天页)
- 保留头部其他功能（会话状态、清空对话）
- 调整样式以适配新布局（移除返回按钮样式）
