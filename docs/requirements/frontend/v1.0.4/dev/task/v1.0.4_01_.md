## 实现要点

### 1. 布局结构
```
┌─────────────────────────────────────────────────────────────┐
│ ☰ │                                                         │ ← L1 入口
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    {children}                               │
│                    (L0 核心层)                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. HamburgerMenu 组件
- 固定在左侧边缘，距顶部 16px，距左侧 8px
- 尺寸: 40x40px 圆形按钮
- 图标: ☰ (三横线)
- 行为: hover 显示背景色 (#f5f5f5)，点击展开侧边栏
- 动画: hover 时 scale: 1.05
- 默认显示，不依赖侧边栏状态

### 3. Sidebar 组件
- 宽度: 260px
- 高度: 100vh
- 背景: #ffffff
- 边框: 右侧 1px #d9d9d9
- 动画: 从左侧滑入 (300ms ease-out)
- 遮罩: 半透明黑色背景 rgba(0,0,0,0.45)

### 5. 底部信息
- 版本号: v1.0.4

### 6. 状态管理
- `sidebarOpen: boolean` - 侧边栏展开/收起状态
- 使用 Context 管理，方便深层组件访问

## 技术实现

```tsx
// BasicLayout/index.tsx
import React, { createContext, useContext, useState } from 'react';
import HamburgerMenu from './components/HamburgerMenu';
import Sidebar from './components/Sidebar';
import styles from './index.less';

export const SidebarContext = createContext<{
  open: boolean;
  setOpen: (open: boolean) => void;
}>({ open: false, setOpen: () => {} });

const BasicLayout: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [sidebarOpen, setSidebarOpen] = useState(false);

  return (
    <SidebarContext.Provider value={{ open: sidebarOpen, setOpen: setSidebarOpen }}>
      <div className={styles.layout}>
        <HamburgerMenu onClick={() => setSidebarOpen(true)} />
        <Sidebar open={sidebarOpen} onClose={() => setSidebarOpen(false)} />
        <main className={styles.main}>{children}</main>
        {sidebarOpen && <div className={styles.overlay} onClick={() => setSidebarOpen(false)} />}
      </div>
    </SidebarContext.Provider>
  );
};

export default BasicLayout;
```
