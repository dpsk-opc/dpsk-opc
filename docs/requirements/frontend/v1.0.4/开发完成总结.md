## 4. 架构设计

### 4.1 分层架构

按照 `design-principles.md` 的四层架构：

| 层级 | 内容 | 实现 |
|------|------|------|
| L0 核心层 | 聊天界面 | `pages/Chat/index.tsx` |
| L1 触达层 | 汉堡菜单 | `components/HamburgerMenu/` |
| L2 功能层 | 侧边栏 | `components/Sidebar/` |
| L3 详情层 | Agent 管理详情页 | `pages/Chat/agents/` |

### 4.2 路由结构

```
/                       → /chat (重定向)
/home                   → /chat (重定向)
/chat                   → BasicLayout + Chat (L0)
/chat/agents            → BasicLayout + AgentList (L2)
/chat/agents/new        → BasicLayout + AgentForm (L3)
/chat/agents/:id        → BasicLayout + AgentDetail (L3)
/chat/agents/:id/edit   → BasicLayout + AgentForm (L3)
/chat/history           → BasicLayout + History (L2)
/chat/settings          → BasicLayout + Settings (L2)
```

## 5. API 服务

### Agent API

| 方法 | 端点 | 功能 |
|------|------|------|
| `AgentService.list()` | GET /agents/ | 获取 Agent 列表 |
| `AgentService.get(id)` | GET /agents/{id} | 获取 Agent 详情 |
| `AgentService.create(data)` | POST /agents/ | 创建 Agent |
| `AgentService.update(id, markdown)` | PUT /agents/{id} | 更新 Agent |
| `AgentService.delete(id)` | DELETE /agents/{id} | 删除 Agent |

### Team API

| 方法 | 端点 | 功能 |
|------|------|------|
| `TeamService.list()` | GET /agents/teams/ | 获取 Team 列表 |
| `TeamService.create(name)` | POST /agents/teams/ | 创建 Team |
| `TeamService.delete(name, force?)` | DELETE /agents/teams/{name} | 删除 Team |

## 9. 遗留问题与建议

### 遗留问题

1. **Markdown 编辑器功能简化**：当前使用 TextArea 实现，如需完整功能（工具栏、预览），建议引入 `@uiw/react-md-editor`
2. **会话历史 API 未对接**：页面已创建，需后端实现会话列表 API
3. **深色模式未实现**：设置项已添加，但主题切换功能待实现

### 后续开发建议

1. **完善 Markdown 编辑器**：考虑集成专业编辑器，提供语法高亮、预览等功能
2. **会话持久化**：添加 localStorage 或 IndexedDB 缓存聊天记录
3. **性能优化**：Agent 列表支持虚拟滚动，优化大数据量场景
4. **可访问性**：完善 ARIA 标签，支持键盘导航
