## 3. 设计原则遵循

### 3.1 分层架构应用

```
┌─────────────────────────────────────────────────────────────┐
│  L0: 核心层 (Core)                                          │
│  ─────────────────────────────────────────────────────────  │
│  聊天界面：输入框 + 消息列表                                  │
│  → 保持不变，作为应用的主功能入口                              │
├─────────────────────────────────────────────────────────────┤
│  L1: 触达层 (Access)                                        │
│  ─────────────────────────────────────────────────────────  │
│  悬浮汉堡菜单 (☰)                                            │
│  → 固定在左侧边缘，hover 显示，点击展开侧边栏                  │
├─────────────────────────────────────────────────────────────┤
│  L2: 功能层 (Feature)                                       │
│  ─────────────────────────────────────────────────────────  │
│  侧边栏面板                                                   │
│  → 包含：Agent 管理、会话历史、设置 等入口                      │
├─────────────────────────────────────────────────────────────┤
│  L3: 详情层 (Detail)                                        │
│  ─────────────────────────────────────────────────────────  │
│  Agent 详情页、编辑器、确认对话框                             │
│  → 按需加载，仅在明确需要时出现                                │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 交互模式应用

| 场景 | 采用模式 |
|------|----------|
| 导航入口 | 侧边栏模式（L1 → L2） |
| Agent 列表 | 列表 + 展开模式 |
| 删除操作 | 确认操作模式 |
| 新建/编辑 | 模态框 + Markdown 编辑器 |

## 4. 技术约束

### 4.1 桌面端特殊考虑

| 约束 | 影响 | 解决方案 |
|------|------|----------|
| 无浏览器标签页 | 无法用多 Tab 切换功能 | 使用侧边栏 + 模态框 |
| 窗口尺寸固定 | 可能小于浏览器视口 | 响应式布局，最小宽度 800px |
| 原生菜单 | 需要与 Web 菜单协调 | 预留 Electron 菜单集成接口 |
| 离线可用 | 需要本地数据缓存 | 考虑 localStorage 缓存 |

### 4.2 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| UmiJS | max | React 框架 |
| Ant Design | 5.x | UI 组件库 |
| React Router | 6.x | 路由管理 |
| electron-builder | - | 打包工具 |
| @uiw/react-md-editor | - | Markdown 编辑器 |
