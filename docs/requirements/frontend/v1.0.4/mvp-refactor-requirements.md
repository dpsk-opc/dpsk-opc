# DPSK-OPC v1.0.4 MVP 调整需求

**版本**: v1.0.4  
**父版本**: v1.0.3  
**日期**: 2026-04-20  
**状态**: 待评审

---

## 1. 概述

### 1.1 背景

v1.0.3 的前端 MVP 采用双页面结构（Home + Chat），随着功能扩展，需要引入分层架构以保持极简体验。

### 1.2 目标

| 目标 | 说明 |
|------|------|
| 单页体验 | 去掉独立的 Home 页面，聊天界面作为唯一核心 |
| 入口整合 | 使用 L1 入口（侧边栏）管理所有非核心功能 |
| 架构统一 | 按照 `design-principles.md` 的四层架构设计 |

---

## 2. 页面结构调整

### 2.1 当前结构（v1.0.3）

```
/home          → 首页（Logo + 开始聊天按钮）
/chat          → 聊天页（独立页面）
```

**问题**：
- 用户需要从首页进入聊天页，体验断层
- 侧边栏等扩展功能无处安放
- 不符合分层架构原则

### 2.2 调整后结构（v1.0.4）

```
/                → 重定向到 /chat
/chat            → 聊天页（L0 核心层）
  ├── /chat/agents         → Agent 管理（L2 功能层）
  ├── /chat/agents/new     → 新建 Agent（L3 详情层）
  ├── /chat/agents/:id     → Agent 详情/编辑（L3）
  └── /chat/settings        → 设置页面（L2）
```

**改进**：
- `/chat` 成为所有功能的父级路由
- 采用嵌套路由，保持层级清晰
- 侧边栏可在任意子路由展开

### 2.3 路由结构图

```
                    /chat (Layout)
                         │
    ┌────────────────────┼────────────────────┐
    │                    │                    │
    ↓                    ↓                    ↓
/chat/agents      /chat/settings        (默认聊天界面)
    │                    │
    ├─ /chat/agents/new  │
    │                    │
    └─ /chat/agents/:id  │
```

## 5. 功能需求

### 5.1 L1 入口：汉堡菜单

| 需求 | 说明 |
|------|------|
| 位置 | 固定在左侧边缘，距顶部 16px |
| 样式 | 40x40px 圆形按钮，图标 ☰ |
| 行为 | hover 显示背景色，点击展开侧边栏 |
| 动画 | hover 时轻微放大 (scale: 1.05) |

**交互细节**：
- 默认隐藏，点击后才出现（首次访问时自动出现）
- 侧边栏展开时，点击遮罩或「返回」关闭
- ESC 键关闭侧边栏

### 5.2 L2 功能：侧边栏

| 需求 | 说明 |
|------|------|
| 宽度 | 260px（桌面端固定） |
| 高度 | 100vh（占满屏幕） |
| 背景 | 白色 `#ffffff` |
| 边框 | 右侧 1px `#d9d9d9` |
| 动画 | 从左侧滑入，300ms |

**导航菜单**：

| 图标 | 名称 | 路由 | 说明 |
|------|------|------|------|
| 🤖 | Agent 管理 | /chat/agents | Agent 列表和管理 |
| 📜 | 会话历史 | /chat/history | 聊天记录列表 |
| ⚙️ | 设置 | /chat/settings | 应用设置 |

**底部信息**：
- 版本号：v1.0.4
- 可选：用户头像、退出登录

### 5.3 L0 核心：聊天界面

**保持不变**，只需确保：
- 页面加载时自动聚焦输入框
- 消息列表区域自适应高度
- 滚动行为符合预期

### 5.4 会话历史（可选 MVP）

| 需求 | 说明 |
|------|------|
| 列表展示 | 显示会话摘要和时间 |
| 空状态 | 「暂无历史会话」+ 引导文案 |
| 点击跳转 | 加载对应会话到当前聊天界面 |

> 注：如果后端会话 API 尚未完善，可推迟此功能。

## 8. Electron 桌面端适配

### 8.1 窗口配置

```javascript
// electron/main.js
const mainWindow = new BrowserWindow({
  width: 1200,
  height: 800,
  minWidth: 800,      // 最小宽度
  minHeight: 600,     // 最小高度
  webPreferences: {
    nodeIntegration: false,
    contextIsolation: true,
  },
});
```

### 8.2 注意事项

| 问题 | 解决方案 |
|------|----------|
| 侧边栏太窄 | 设置 `minWidth: 800`，侧边栏固定 260px |
| 输入框无法聚焦 | Electron 需启用 `nodeIntegration: false` |
| 右键菜单 | 禁用默认右键，使用自定义菜单 |
| 窗口控制 | 使用系统原生窗口控制栏 |
