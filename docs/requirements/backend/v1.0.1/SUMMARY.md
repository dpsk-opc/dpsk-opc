## 一、版本概述

Agent 模块（v1.0.1）是 DPSK-OPC 后端的核心组件，负责实现"数字员工"的完整生命周期管理。本版本基于已就绪的消息总线模块（v1.0.0）和安全模块，提供 Agent 的静态定义、动态实例化、技能执行、模型路由、经验记忆等核心能力。

### 核心价值

- **标准化 Agent 抽象**：将 AI 能力封装为可定义、可配置、可管理的"数字员工"
- **安全的执行环境**：Agent 运行于独立沙箱，默认零权限，所有操作通过安全模块授权
- **灵活的通信机制**：与消息总线深度集成，支持点对点、发布订阅、群组任务等多种模式
- **智能的经验复用**：基于精确匹配的本地缓存，减少重复计算和 API 调用

## 三、技术架构

### 3.1 模块分层

```
┌─────────────────────────────────────────────────────────┐
│                    管理 API 层                           │
│         (FastAPI /api/v1/agents/*)                      │
├─────────────────────────────────────────────────────────┤
│                   AgentManager 层                        │
│    (生命周期管理 / 实例调度 / 权限协调)                    │
├─────────────────────────────────────────────────────────┤
│                 AgentSpawner 层                          │
│        (沙箱创建 / 实例池 / 队列管理)                      │
├───────────────────┬─────────────────┬────────────────────┤
│   AgentRegistry   │    经验池       │    日志服务        │
│   (定义管理)       │   (SQLite)      │   (结构化日志)     │
├───────────────────┴─────────────────┴────────────────────┤
│                    沙箱内 Agent                          │
│           (agent_runner + skills + experience)            │
├─────────────────────────────────────────────────────────┤
│                   消息总线 (Bus)                          │
├─────────────────────────────────────────────────────────┤
│                   安全模块 (Security)                     │
└─────────────────────────────────────────────────────────┘
```

### 3.2 关键数据流

**Agent 实例创建**：
```
用户/系统 → API → AgentManager.spawn_agent()
  → AgentRegistry.get(agent_id)
  → AgentSpawner.spawn()
  → SecurityModule.create_sandbox()
  → 注入环境变量 + 启动 agent_runner
  → Agent 注册到 Bus
  → 返回 AgentHandle
```

**任务执行**：
```
调用方 → Bus.request(Target(AGENT, agent_id), TaskRequest)
  → agent_runner 接收
  → 经验池精确匹配
    → 命中: 直接返回缓存结果
    → 未命中: 执行技能 → 异步存储经验 → 返回结果
```

## 八、开发建议

### 8.1 实现顺序

1. **Phase 1（基础框架）**：defs.py + parser.py + registry.py + runner.py
2. **Phase 2（实例化）**：spawner.py + 安全模块集成
3. **Phase 3（管理）**：manager.py + api.py + 技能系统
4. **Phase 4（高级功能）**：经验池完善、并发控制、可观测性
5. **Phase 5（测试）**：单元测试 + 集成测试

### 8.2 重点关注

- **安全隔离**：Agent 必须运行于沙箱，所有敏感操作通过安全模块代理
- **通信可靠**：与消息总线的集成必须可靠，支持超时和重试
- **可观测性**：从第一天就考虑日志和监控，便于问题排查
