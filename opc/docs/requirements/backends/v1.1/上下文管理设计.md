1. 概述
   1.1 背景
   在 AI-IM 系统中，每个 AI 好友（Agent）需要具备类人聊天与任务执行能力。随着对话长度增加，全量历史会超出大模型上下文窗口，同时无差别记忆也会造成“AI 感”过重。为此，设计一套多级记忆系统，在有限 token 预算内实现自然的长期记忆。

1.2 设计目标
三级记忆：工作记忆（L0）、摘要记忆（L1）、长期事实记忆（L2），模拟人脑记忆机制。

动态上下文：依据对话状态智能拼接人设、近期对话、往事摘要、深层记忆。

语义检索：基于向量数据库 JVector 实现“按需回忆”。

多 Agent 隔离：每个 Agent 拥有独立记忆空间。

引用与定位：支持 @Agent 和 @历史消息，精准引入上下文。

        }
    }

8.3 FactManager（双重存储）
java
@Service
public class FactManager {
private final LongTermFactRepository factRepo;
private final EmbeddingModel embeddingModel;
private final EmbeddingStore<TextSegment> embeddingStore;

    @Async
    public void processFacts(String ownerCode, String targetCode, String conversationCode,
                             List<ExtractedFact> facts) {
        for (ExtractedFact f : facts) {
            // 1. 存入关系表
            LongTermFact entity = new LongTermFact();
            entity.setCode("fact_" + uuid());
            entity.setOwnerCode(ownerCode);
            entity.setTargetCode(targetCode);
            entity.setFactType(f.getType());
            entity.setFactContent(f.getContent());
            entity.setImportance(f.getImportance());
            factRepo.save(entity);

            // 2. 向量化
            Metadata metadata = new Metadata()
                .put("type", "fact")
                .put("owner_code", ownerCode)
                .put("target_code", targetCode)
                .put("conversation_code", conversationCode)
                .put("timestamp", Instant.now().toString())
                .put("importance", String.valueOf(f.getImportance()));
            TextSegment segment = TextSegment.from(f.getContent(), metadata);
            Embedding embedding = embeddingModel.embed(segment).content();
            embeddingStore.add(embedding, segment);
        }
    }
}
8.4 JVector 集成示例
java
public class JVectorEmbeddingStore implements EmbeddingStore<TextSegment> {
private final JVectorClient client; // 封装 JVector 原生 API
private final String collectionName;

    @Override
    public String add(Embedding embedding, TextSegment textSegment) {
        String id = textSegment.metadata().getString("id");
        if (id == null) id = UUID.randomUUID().toString();
        client.insert(collectionName, id, embedding.vectorAsList(), 
                      textSegment.text(), textSegment.metadata().toMap());
        return id;
    }

    @Override
    public List<EmbeddingMatch<TextSegment>> findRelevant(Embedding referenceEmbedding,
                                                          int maxResults, double minScore) {
        List<SearchResult> results = client.search(collectionName,
                                                   referenceEmbedding.vectorAsList(), maxResults);
        return results.stream()
            .map(r -> new EmbeddingMatch<>(r.getScore(), r.getId(),
                    new Embedding(r.getVector()),
                    TextSegment.from(r.getText(), new Metadata(r.getMetadata()))))
            .filter(m -> m.score() >= minScore)
            .collect(Collectors.toList());
    }
}
8.5 语义检索（带衰减）
java
public List<MemoryFragment> retrieveMemories(String query, String ownerCode,
String targetCode, int k) {
Embedding queryEmb = embeddingModel.embed(query).content();
List<EmbeddingMatch<TextSegment>> matches = embeddingStore.findRelevant(queryEmb, k * 2, 0.7);

    Instant now = Instant.now();
    return matches.stream()
        .filter(m -> ownerCode.equals(m.embedded().metadata().getString("owner_code")))
        .map(m -> {
            double importance = Double.parseDouble(m.embedded().metadata().getString("importance"));
            Instant ts = Instant.parse(m.embedded().metadata().getString("timestamp"));
            long days = ChronoUnit.DAYS.between(ts, now);
            double decay = Math.exp(-0.01 * days);   // λ=0.01
            double adjustedScore = m.score() * importance * decay;
            return new MemoryFragment(m.embedded().text(), adjustedScore);
        })
        .sorted((a,b) -> Double.compare(b.score, a.score))
        .limit(k)
        .collect(Collectors.toList());
}

   9.1 组装流程（伪代码）
   java
   public class ContextAssembler {

   public Prompt assemble(UserMessage userMsg, String targetAgentCode, String conversationCode) {
   Agent agent = agentRepo.findByCode(targetAgentCode);
   StringBuilder systemPart = new StringBuilder();
   StringBuilder historyPart = new StringBuilder();

        // 1. Agent 人设（从 t_agent.system_prompt）
        systemPart.append(agent.getSystemPrompt()).append("\n");

        // 2. 长期结构化事实（从 t_long_term_fact 直接注入）
        List<LongTermFact> facts = factRepo.findByOwnerCodeAndTargetCode(targetAgentCode, userMsg.getUserCode());
        if (!facts.isEmpty()) {
            systemPart.append("[你对用户的长期记忆]\n");
            facts.forEach(f -> systemPart.append("- ").append(f.getFactContent()).append("\n"));
            systemPart.append("\n");
        }

        // 3. L1 摘要（若有）
        MemorySummary summary = summaryRepo.findLatest(conversationCode, targetAgentCode);
        if (summary != null) {
            historyPart.append("[近期往事] ").append(summary.getSummaryText()).append("\n\n");
        }

        // 4. @历史消息引用
        if (userMsg.getQuoteMessageCode() != null) {
            Message quoted = messageRepo.findByCode(userMsg.getQuoteMessageCode());
            if (quoted != null) {
                List<Message> context = messageRepo.findContext(quoted.getCode(), 2);
                historyPart.append("[被引用的对话记录]\n");
                context.forEach(m -> historyPart.append(formatMessage(m)).append("\n"));
                historyPart.append("\n");
            }
        }

        // 5. L2 按需检索
        if (needRetrieve(userMsg)) {
            List<MemoryFragment> retrieved = factManager.retrieveMemories(
                userMsg.getContent(), targetAgentCode, userMsg.getUserCode(), 3);
            if (!retrieved.isEmpty()) {
                historyPart.append("[你可能想起来的旧事]\n");
                retrieved.forEach(f -> historyPart.append("- ").append(f.getText()).append("\n"));
                historyPart.append("\n");
            }
        }

        // 6. L0 工作记忆
        ChatMemory memory = getChatMemory(conversationCode, targetAgentCode);
        memory.messages().forEach(m -> historyPart.append(formatChatMessage(m)).append("\n"));

        // 7. 当前消息
        historyPart.append("用户: ").append(userMsg.getContent());

        return Prompt.from(SystemMessage.from(systemPart.toString()),
                          HumanMessage.from(historyPart.toString()));
   }

   private boolean needRetrieve(UserMessage msg) {
   String text = msg.getContent();
   return text.contains("还记得") || text.contains("之前") || text.contains("上次");
   }
   }

10. @ 功能处理
    10.1 @Agent
    从消息文本解析首个 @AgentName。

匹配 t_agent.name，切换目标 owner_code。

后续所有记忆操作均基于该 Agent。

10.2 @历史消息
根据 quote_message_code 查询 t_message。

取出该消息及其前后各 2 条作为引用上下文。

若引用消息已在 L0 窗口内，则不再重复注入。

11. 记忆更新异步流水线
    11.1 触发点
    DatabaseChatMemoryStore.updateMessages() 中检测到消息被移出 L0 窗口时，调用 MemoryManager.onMessagesEvicted(key, evictedMessages)。

11.2 MemoryManager 实现
java
@Service
public class MemoryManager {
@Autowired private SummaryManager summaryManager;
@Autowired private FactManager factManager;
@Autowired private FactExtractor factExtractor;

    @Async
    public void onMessagesEvicted(MemoryKey key, List<Message> evicted) {
        // L1 摘要更新
        summaryManager.updateSummary(key, evicted);

        // L2 事实提取
        List<ExtractedFact> facts = factExtractor.extractFacts(key.getOwner(), evicted);
        if (!facts.isEmpty()) {
            String targetCode = resolveTargetCode(key.getConversationCode());
            factManager.processFacts(key.getOwnerCode(), targetCode, 
                                     key.getConversationCode(), facts);
        }
    }
}
11.3 异步与幂等
使用 @Async 或消息队列执行，不阻塞对话。

幂等性通过消息 code 范围判断，若对应 start_message_code 的摘要已存在则跳过。

13. 异常与边界处理
    DB/LLM 故障：异步更新失败不阻塞主流程，仅记录日志并告警。

窗口未满：不触发任何 L1/L2 更新，系统仅使用 L0。

Agent 切换：每个 Agent 独立持有 ChatMemory 实例（memoryId 含 owner_code）。

JVector 故障：检索降级，直接跳过 L2 注入；事实写入失败时重试或补偿。

事实冲突：相同类型事实可更新为最新，旧记录标记为 is_deleted=1 或设置过期。
