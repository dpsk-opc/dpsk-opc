# 任务与定时任务模块概要设计

## 1. 概述

### 1.1 目标

提供一个通用任务引擎，支持多种任务类型（定时、手动、AI 指令等），其中定时任务由 db-scheduler 驱动。核心能力：

- 任务的 CRUD、启用/禁用
- 消费者注册机制（类似 Kafka Consumer）
- 任务触发时动态路由到对应消费者
- 支持后续扩展（如多触发器、任务依赖）

### 1.2 技术选型

- **db-scheduler (16.11.0)** – 仅用于定时任务调度（已在 opc-core/pom.xml 中引入）
- **H2 / MySQL** – 存储业务表
- **Spring Boot** – 生命周期管理、依赖注入
- **MyBatis-Plus** – 数据访问层

### 1.3 模块职责

| 模块 | 职责 |
|------|------|
| **opc-core** | 定义核心模型、接口（Repository、TaskConsumer）、TaskManager、TaskConfiguration、db-scheduler 集成 |
| **opc-im** | 提供 Repository 实现、DO 模型、DAO、Mapper、Controller |

## 2. 数据库设计

### 2.1 表 t_task – 通用任务定义表

设计原则：只存储所有任务类型共有的字段，专有配置（如 cron 表达式）全部放入 parameters JSON 字段。

```sql
-- =============================================
-- 表名: t_task
-- 描述: 通用任务定义表，支持多种任务类型
-- =============================================
CREATE TABLE IF NOT EXISTS `t_task` (
    `id`                BIGINT AUTO_INCREMENT PRIMARY KEY,
    `code`              VARCHAR(64)    NOT NULL COMMENT '任务编码，唯一标识',
    `name`              VARCHAR(128)   NOT NULL COMMENT '任务名称',
    `task_type`         VARCHAR(32)    NOT NULL COMMENT '任务类型: SCHEDULED, MANUAL, AI_COMMAND, WORKFLOW',
    `status`            VARCHAR(16)    NOT NULL DEFAULT 'ENABLED' COMMENT '状态: ENABLED, DISABLED, PAUSED',
    `consumer_key`      VARCHAR(64)    NOT NULL COMMENT '消费者标识，用于路由到具体执行逻辑',

    -- 通用参数（JSON），存放任务特有配置，例如：
    -- 定时任务：{"cron": "0 0 9 * * ?", "timezone": "Asia/Shanghai"}
    -- 手动任务：{}
    -- AI指令：{"prompt": "..."}
    `parameters`        TEXT           NOT NULL COMMENT 'JSON格式的参数，存储任务特有配置',

    -- 归属与元数据（便于管理）
    `agent_code`        VARCHAR(64)    NULL COMMENT '所属Agent编码',
    `conversation_code` VARCHAR(64)    NULL COMMENT '所属会话编码',
    `create_time`       TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time`       TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '更新时间',
    `is_deleted`        TINYINT(1)     NOT NULL DEFAULT 0 COMMENT '逻辑删除: 0=未删除, 1=已删除',

    UNIQUE INDEX `uk_code` (`code`),
    INDEX `idx_task_type` (`task_type`),
    INDEX `idx_status` (`status`),
    INDEX `idx_consumer_key` (`consumer_key`),
    INDEX `idx_agent_conversation` (`agent_code`, `conversation_code`)
) COMMENT '通用任务定义表';
```

parameters 字段示例：

```json
// 定时任务
{"cron": "0 0 9 * * ?", "timezone": "Asia/Shanghai", "retry": 3}

// 手动任务（无特殊配置）
{}

// AI 指令任务
{"prompt": "生成日报并发送", "model": "gpt-4"}

// 工作流任务（预留）
{"workflow_id": "wf_123", "inputs": {...}}
```

```java
package com.xiaomizhou.dpsk.task.consumer;

import lombok.extern.slf4j.Slf4j;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 任务消费者注册表。
 *
 * @author eason - vipzhsh@163.com
 */
@Slf4j
public class TaskConsumerRegistry {

    private final Map<String, TaskConsumer> consumers = new ConcurrentHashMap<>();

    /**
     * 注册消费者。
     */
    public void register(TaskConsumer consumer) {
        TaskConsumer existing = consumers.putIfAbsent(consumer.getConsumerKey(), consumer);
        if (existing != null) {
            log.warn("Consumer key '{}' already registered, skipping duplicate", consumer.getConsumerKey());
        } else {
            log.info("Consumer registered: {}", consumer.getConsumerKey());
        }
    }

    /**
     * 获取消费者，不存在则返回 null。
     */
    public TaskConsumer getConsumer(String key) {
        return consumers.get(key);
    }

    /**
     * 检查消费者是否已注册。
     */
    public boolean hasConsumer(String key) {
        return consumers.containsKey(key);
    }
}
```

### 3.5 db-scheduler 封装（opc-core）

```java
package com.xiaomizhou.dpsk.task.scheduler;

import com.github.kagkarlsson.scheduler.Scheduler;
import com.github.kagkarlsson.scheduler.SchedulerBuilder;
import com.github.kagkarlsson.scheduler.task.TaskInstanceId;
import lombok.extern.slf4j.Slf4j;

import javax.sql.DataSource;
import java.time.Duration;
import java.time.Instant;

/**
 * db-scheduler 封装，仅处理定时任务。
 * <p>
 * 每个业务定时任务在 db-scheduler 中对应一个 RecurringTask，
 * taskName 格式为 "task_" + taskCode。
 *
 * @author eason - vipzhsh@163.com
 */
@Slf4j
public class DbSchedulerWrapper {

    private static final String TASK_PREFIX = "task_";

    private final Scheduler scheduler;

    public DbSchedulerWrapper(DataSource dataSource) {
        this.scheduler = Scheduler.create(dataSource)
                .threads(4)
                .pollingInterval(Duration.ofSeconds(10))
                .build();
    }

    /**
     * 启动调度器。
     */
    public void start() {
        scheduler.start();
        log.info("DbScheduler started");
    }

    /**
     * 停止调度器。
     */
    public void stop() {
        scheduler.stop();
        log.info("DbScheduler stopped");
    }

    /**
     * 获取调度器中的任务名称，格式为 "task_" + taskCode。
     */
    public static String toTaskName(String taskCode) {
        return TASK_PREFIX + taskCode;
    }

    /**
     * 检查任务是否已被调度。
     */
    public boolean isScheduled(String taskCode) {
        return scheduler.getScheduledExecutionFor(
                TaskInstanceId.of(toTaskName(taskCode), taskCode)
        ).isPresent();
    }
}
```

> **设计说明**：db-scheduler 16.x 中，定时任务的调度方式是预先定义 `RecurringTask`（包含 cron 表达式），通过 `scheduler.schedule()` 注册、`scheduler.deschedule()` 取消。本框架在 `TaskConfiguration` 启动时动态注册所有 `RecurringTask`，具体见 3.7 节。

#### TaskManagerImpl.java

```java
package com.xiaomizhou.dpsk.task;

import com.github.kagkarlsson.scheduler.Scheduler;
import com.github.kagkarlsson.scheduler.SchedulerBuilder;
import com.github.kagkarlsson.scheduler.task.TaskInstanceId;
import com.github.kagkarlsson.scheduler.task.VoidTask;
import com.github.kagkarlsson.scheduler.task.helper.Tasks;
import com.github.kagkarlsson.scheduler.task.schedule.Schedules;
import com.xiaomizhou.dpsk.task.consumer.TaskConsumer;
import com.xiaomizhou.dpsk.task.consumer.TaskConsumerRegistry;
import com.xiaomizhou.dpsk.task.model.Task;
import com.xiaomizhou.dpsk.task.model.TaskConsumeResult;
import com.xiaomizhou.dpsk.task.model.TaskExecutionLog;
import com.xiaomizhou.dpsk.task.repository.TaskExecutionLogRepository;
import com.xiaomizhou.dpsk.task.repository.TaskRepository;
import com.xiaomizhou.dpsk.task.scheduler.DbSchedulerWrapper;
import lombok.extern.slf4j.Slf4j;

import javax.sql.DataSource;
import java.time.Duration;
import java.time.Instant;
import java.util.Date;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

/**
 * 任务管理器实现。
 *
 * @author eason - vipzhsh@163.com
 */
@Slf4j
public class TaskManagerImpl implements TaskManager {

    private final TaskRepository taskRepository;
    private final TaskExecutionLogRepository executionLogRepository;
    private final TaskConsumerRegistry consumerRegistry;
    private final Scheduler scheduler;
    private final ExecutorService executor;

    public TaskManagerImpl(TaskRepository taskRepository,
                           TaskExecutionLogRepository executionLogRepository,
                           TaskConsumerRegistry consumerRegistry,
                           DataSource dataSource) {
        this.taskRepository = taskRepository;
        this.executionLogRepository = executionLogRepository;
        this.consumerRegistry = consumerRegistry;
        this.scheduler = Scheduler.create(dataSource)
                .threads(4)
                .pollingInterval(Duration.ofSeconds(10))
                .build();
        this.executor = Executors.newCachedThreadPool();
    }

    // ---------- TaskManager 接口实现 ----------

    @Override
    public String createTask(Task task) {
        taskRepository.save(task);
        if (task.isScheduled() && task.isEnabled()) {
            scheduleRecurringTask(task);
        }
        return task.getCode();
    }

    @Override
    public void updateTask(Task task) {
        Task old = taskRepository.findByCode(task.getCode());
        if (old == null) {
            throw new IllegalArgumentException("Task not found: " + task.getCode());
        }
        taskRepository.update(task);

        // 如果原来是定时任务，先取消调度
        if (old.isScheduled() && scheduler.getScheduledExecutionFor(
                TaskInstanceId.of(DbSchedulerWrapper.toTaskName(old.getCode()), old.getCode())).isPresent()) {
            scheduler.deschedule(DbSchedulerWrapper.toTaskName(old.getCode()), old.getCode());
            log.info("Descheduled old task: {}", old.getCode());
        }

        // 如果更新后仍是启用的定时任务，重新调度
        if (task.isScheduled() && task.isEnabled()) {
            scheduleRecurringTask(task);
        }
    }

    @Override
    public void deleteTask(String code) {
        taskRepository.deleteByCode(code);
        // 取消调度
        if (scheduler.getScheduledExecutionFor(
                TaskInstanceId.of(DbSchedulerWrapper.toTaskName(code), code)).isPresent()) {
            scheduler.deschedule(DbSchedulerWrapper.toTaskName(code), code);
            log.info("Descheduled deleted task: {}", code);
        }
    }

    @Override
    public void enableTask(String code) {
        Task task = taskRepository.findByCode(code);
        if (task == null) {
            throw new IllegalArgumentException("Task not found: " + code);
        }
        if (task.isEnabled()) {
            log.info("Task already enabled: {}", code);
            return;
        }
        taskRepository.updateStatus(code, Task.STATUS_ENABLED);
        task.setStatus(Task.STATUS_ENABLED);

        if (task.isScheduled()) {
            scheduleRecurringTask(task);
        }
    }

    @Override
    public void disableTask(String code) {
        Task task = taskRepository.findByCode(code);
        if (task == null) {
            throw new IllegalArgumentException("Task not found: " + code);
        }
        taskRepository.updateStatus(code, Task.STATUS_DISABLED);
        task.setStatus(Task.STATUS_DISABLED);

        // 取消调度
        if (scheduler.getScheduledExecutionFor(
                TaskInstanceId.of(DbSchedulerWrapper.toTaskName(code), code)).isPresent()) {
            scheduler.deschedule(DbSchedulerWrapper.toTaskName(code), code);
            log.info("Descheduled disabled task: {}", code);
        }
    }

    @Override
    public TaskConsumeResult triggerTask(String code, String triggerType, Map<String, Object> triggerContext) {
        Task task = taskRepository.findByCode(code);
        if (task == null) {
            throw new IllegalArgumentException("Task not found: " + code);
        }
        if (!task.isEnabled()) {
            throw new IllegalStateException("Task is not enabled: " + code);
        }
        return executeTask(task, triggerType, triggerContext);
    }

    @Override
    public Task getTask(String code) {
        return taskRepository.findByCode(code);
    }

    @Override
    public List<Task> listEnabledTasks() {
        return taskRepository.findAllEnabled();
    }

    @Override
    public void loadAllScheduledTasksOnStartup() {
        List<Task> tasks = taskRepository.findAllEnabledScheduled();
        for (Task task : tasks) {
            try {
                scheduleRecurringTask(task);
                log.info("Loaded scheduled task on startup: {}", task.getCode());
            } catch (Exception e) {
                log.error("Failed to load scheduled task: {}", task.getCode(), e);
            }
        }
    }

    @Override
    public void stop() {
        log.info("Stopping TaskManager...");
        scheduler.stop();
        executor.shutdown();
        log.info("TaskManager stopped");
    }

    // ---------- 内部方法 ----------

    /**
     * 将定时任务注册到 db-scheduler。
     * <p>
     * 使用 db-scheduler 16.x 的 RecurringTask + Schedules.cron() 模式，
     * 无需手动计算下次执行时间，由调度器自动管理 cron 调度。
     */
    private void scheduleRecurringTask(Task task) {
        String cron = extractCron(task.getParameters());
        if (cron == null || cron.isBlank()) {
            log.warn("Task {} is SCHEDULED but has no cron expression", task.getCode());
            return;
        }

        String taskName = DbSchedulerWrapper.toTaskName(task.getCode());
        String taskCode = task.getCode();

        com.github.kagkarlsson.scheduler.task.Task<Void> recurringTask =
                Tasks.recurring(taskName, Schedules.cron(cron))
                        .execute((instance, ctx) -> {
                            // 调度器触发时，重新从数据库加载最新任务状态
                            Task current = taskRepository.findByCode(taskCode);
                            if (current != null && current.isEnabled()) {
                                executeTask(current, TaskExecutionLog.TRIGGER_SCHEDULED, null);
                            } else {
                                log.warn("Scheduled task {} is no longer available or enabled, skipping", taskCode);
                            }
                        });

        scheduler.schedule(recurringTask, Instant.now());
        log.info("Scheduled recurring task: code={}, cron={}", task.getCode(), cron);
    }

    /**
     * 执行任务（同步执行，由调用方决定是否异步）。
     */
    private TaskConsumeResult executeTask(Task task, String triggerType, Map<String, Object> ctx) {
        String logId = startExecutionLog(task, triggerType);
        try {
            TaskConsumer consumer = consumerRegistry.getConsumer(task.getConsumerKey());
            if (consumer == null) {
                String msg = "No consumer registered for key: " + task.getConsumerKey();
                log.error(msg);
                failExecutionLog(logId, msg);
                return TaskConsumeResult.fail(msg);
            }

            TaskConsumeResult result = consumer.consume(task, ctx != null ? ctx : Map.of());
            if (result.isSuccess()) {
                completeExecutionLog(logId, result.getResult());
            } else {
                failExecutionLog(logId, result.getErrorMessage());
            }
            return result;
        } catch (Exception e) {
            log.error("Task execution failed: code={}", task.getCode(), e);
            failExecutionLog(logId, e.getMessage());
            return TaskConsumeResult.fail(e.getMessage());
        }
    }

    /**
     * 从 parameters JSON 中提取 cron 表达式。
     * 使用 Jackson（项目已有依赖），增加容错处理。
     */
    private String extractCron(String parameters) {
        if (parameters == null || parameters.isBlank()) {
            return null;
        }
        try {
            com.fasterxml.jackson.databind.ObjectMapper mapper = new com.fasterxml.jackson.databind.ObjectMapper();
            com.fasterxml.jackson.databind.JsonNode node = mapper.readTree(parameters);
            return node.has("cron") ? node.get("cron").asText() : null;
        } catch (Exception e) {
            log.warn("Failed to parse parameters JSON: {}", parameters, e);
            return null;
        }
    }

    // ---- 执行日志方法 ----

    private String startExecutionLog(Task task, String triggerType) {
        TaskExecutionLog execLog = TaskExecutionLog.builder()
                .taskCode(task.getCode())
                .consumerKey(task.getConsumerKey())
                .triggerType(triggerType)
                .status(TaskExecutionLog.LOG_STATUS_RUNNING)
                .startTime(new Date())
                .build();
        executionLogRepository.save(execLog);
        return String.valueOf(execLog.getId());
    }

    private void completeExecutionLog(String logId, String result) {
        TaskExecutionLog execLog = executionLogRepository.findByLogId(Long.parseLong(logId));
        if (execLog != null) {
            execLog.setStatus(TaskExecutionLog.LOG_STATUS_SUCCESS);
            execLog.setEndTime(new Date());
            execLog.setDurationMs(System.currentTimeMillis() - execLog.getStartTime().getTime());
            execLog.setResult(result);
            executionLogRepository.update(execLog);
        }
    }

    private void failExecutionLog(String logId, String errorMessage) {
        TaskExecutionLog execLog = executionLogRepository.findByLogId(Long.parseLong(logId));
        if (execLog != null) {
            execLog.setStatus(TaskExecutionLog.LOG_STATUS_FAILED);
            execLog.setEndTime(new Date());
            execLog.setDurationMs(System.currentTimeMillis() - execLog.getStartTime().getTime());
            execLog.setErrorMessage(errorMessage);
            executionLogRepository.update(execLog);
        }
    }
}
```

## 6. 关键流程说明

### 6.1 创建定时任务

1. 调用 `taskManager.createTask(task)`，`task.taskType = SCHEDULED`，`parameters` 中包含 `{"cron":"0 0 9 * * ?"}`。
2. 任务写入 `t_task` 表。
3. 自动调用 `scheduleRecurringTask`，使用 `Tasks.recurring(taskName, Schedules.cron(cron))` 注册到 db-scheduler。
4. db-scheduler 根据 cron 表达式自动调度，无需手动计算下次执行时间。

### 6.2 定时触发

1. db-scheduler 根据 cron 表达式触发 `RecurringTask` 的 `execute` 回调。
2. 回调内部重新从数据库加载最新任务状态，确认仍然启用后调用 `executeTask`。
3. 根据 `consumerKey` 找到消费者，执行 `consume` 方法。
4. 记录执行日志到 `t_task_execution_log`。

### 6.3 手动/AI 触发

1. 直接调用 `taskManager.triggerTask(code, "MANUAL", ctx)`。
2. 同步执行消费者逻辑（若需异步可由调用方自行包装）。
3. 同样记录执行日志。

### 6.4 启动加载

1. Spring 容器初始化时，`TaskConfiguration` 自动创建 `TaskManager` 并调用 `loadAllScheduledTasksOnStartup()`。
2. 从 `t_task` 表加载所有 `task_type = SCHEDULED` 且 `status = ENABLED` 的任务。
3. 逐一调用 `scheduleRecurringTask` 注册到 db-scheduler。

### 6.5 关闭清理

1. Spring 容器关闭时，`TaskManager.stop()` 被调用（通过 `@PreDestroy` 或 `DisposableBean`）。
2. 停止 db-scheduler 调度器。
3. 关闭执行线程池。

## 7. 与现有系统的集成

### 7.1 与工具系统集成

- `TaskConsumer.consume()` 的 `triggerContext` 可注入 `ToolRegistry` 引用，使定时任务能调用工具。
- 执行日志中可记录工具调用结果。

### 7.2 与 Agent 系统集成

- `Task.agentCode` 和 `Task.conversationCode` 标识任务归属。
- 任务触发时，可通过 `agentCode` 获取 Agent 上下文（memory、配置等）。
- 执行结果可写回对应会话。

## 8. 扩展性说明

- **新增任务类型**：只需在 `Task` 模型中添加新的 `TYPE_*` 常量，业务消费者可根据 `taskType` 做不同处理。
- **多触发器**：未来可将 `parameters` 中的 cron 拆出到独立的 `t_task_trigger` 表，支持一个任务多个触发规则。
- **任务依赖**：可在 `parameters` 中添加 `depends_on` 字段，或在执行前检查前置任务状态。
- **执行日志清理**：可通过定时任务对 `t_task_execution_log` 按时间范围归档或逻辑删除。
